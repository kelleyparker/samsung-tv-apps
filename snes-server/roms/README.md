# ROMs served from the PC

Put your own ROMs here (`.sfc`, `.smc`, `.swc`, `.fig`, `.zip`) to serve them to the TV over the LAN with `python serve.py`. The server lists them at `/roms.json`.

The TV app doesn't load games from here yet. That comes with the game picker. For now, games are baked into the app from `snes/roms/`.

ROMs are git-ignored. Only use games you own.
